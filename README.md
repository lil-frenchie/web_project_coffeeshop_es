# Triple Espresso

Triple Esspreso es una página web moderna y atractiva para una cafetería temática de gatos ubicada en la ciudad ficticia de Triple Peaks. El sitio busca proyectar un ambiente acogedor y creativo, ideal para estudiantes y amantes de los gatos, ofreciendo información sobre horarios, ubicación y una sección interactiva de videorecetas.

🚀 Tecnologías Utilizadas
HTML5 Semántico: Para una estructura clara y accesible.

CSS3 (Flexbox y Posicionamiento): Para el diseño del layout y la disposición de elementos.

Metodología BEM (Block Element Modifier): Utilizada para mantener un código CSS organizado, escalable y fácil de mantener.

Fuentes de Google: Integración de Inter y Noto Serif para una tipografía de alta calidad.

Normalización de estilos: Uso de normalize.css para asegurar la consistencia entre navegadores.

📖 Funcionalidad
El proyecto actualmente cuenta con:

Header Hero: Una sección de bienvenida con diseño visual fuerte que incluye navegación, descripción y horarios.

Navegación Intuitiva: Enlaces rápidos a las secciones clave.

Sección de Recetas: Integración de videos de YouTube (iframe) que permiten a los usuarios aprender a preparar café en diferentes métodos (Aeropress y Prensa Francesa).

Diseño Limpio: Uso de variables visuales y alineación precisa mediante contenedores de ancho máximo.

🔮 Planes de Mejora
Para futuras actualizaciones, tengo planeado implementar:

Sección de Reservas Funcional: Crear un formulario dinámico donde los usuarios puedan solicitar una mesa o tiempo con los gatos.

Galería de Gatos: Implementar una sección de "Nuestros Anfitriones" con imágenes y descripciones de los gatos del café, posiblemente usando CSS Grid para un layout más dinámico.

Modo Oscuro: Añadir una paleta de colores alternativa para mejorar la experiencia de lectura nocturna.
